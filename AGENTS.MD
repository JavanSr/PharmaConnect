## Task Execution Rule
Large feature initiatives must be implemented from task files in `/tasks`.
Do not rewrite the whole system when implementing a task.
Prefer additive, backward-compatible changes.
Preserve existing MVP flows unless explicitly instructed otherwise.

## Website Source Rule
The deployed marketing website source lives only in `/website`.
Do not create or maintain root-level landing pages or alternate website source trees.
Do not redesign or replace the landing page without explicit approval.
