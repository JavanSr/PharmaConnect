The founder's original vision

Patient safety at every dispensing event

No community pharmacy should have to rely on memory alone for interaction checking. PharmaConnect keeps safety practical: visible alerts, pharmacist review, and privacy-by-design patient UUID handling.

Drug interaction checking - MINOR through CONTRAINDICATED severity
Contraindication alerts - pregnancy, elderly, renal, allergy
Anonymous patient UUID - no names, no national IDs, PDPC-conscious
"I have seen preventable harm happen. PharmaConnect was built to stop it."- Elihaki M. Y. Javan, Founder & Pharmaceutical Technologist

Counselling note and routine pharmacist awareness.

MODERATE

NHIF claims flow

Claims readiness without end-of-day panic

The current claims flow focuses on verification, validation, offline queueing, and fast rejected-claim follow-up so pharmacies can improve claim success rate.

1

Verify

Patient presents NHIF card. Member is verified via Breeze API in under 3 seconds.

→
2

Dispense

Drug is dispensed and ICD-10 context is captured for claim readiness.

→
3

Validate

Claims scrubber checks required fields, diagnosis code, item, and member status.

→
4

Submit

Batch is submitted through the NHIF pathway at the end of the day.

→
5

Track

Status is tracked and rejected claims are flagged for follow-up.
