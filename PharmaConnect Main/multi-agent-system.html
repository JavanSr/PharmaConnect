🧠 Orchestrator Agent
Task router · Context manager · Retry controller
Inputs
Raw event streamUser role + tierPharmacy contextPriority level
Decision Logic
1Classify event type — CLINICAL / INVENTORY / COMPLIANCE / BI / DATA
2Check tier gate — ADDO: contras only · STANDARD+: full interaction check
3Inject pharmacy context (offline state, subscription, region)
4Route to ≥1 agents in parallel; await confidence ≥ 0.85
5If score < 0.85 → re-route with expanded context or escalate to PIC
Outputs
Routed task payloadContext-enriched promptEscalation flag
Failure Handling
Circuit-breaker: 5 fails/min → openOffline: queue + sync on restore
🔬 Clinical Safety Agent
Drug interactions · Contraindications · Dose calc · Counselling
Inputs
Drug cart (product IDs)Patient session flagsActive ingredientsWeight/Age (optional)
Decision Logic
1Cross-reference all drug pairs vs. DrugInteraction table (MINOR → CONTRAINDICATED)
2Scan each drug against patient flags (pregnancy, G6PD, renal, hepatic)
3Run Clark's rule dose check if weight & age present
4Check AI Counselling Cache (flagsHash) — skip regen on cache hit
5MAJOR/CONTRAINDICATED → require PIC PIN; write OverrideLog (immutable)
Outputs
Severity-coded alertCounselling textPIN override requestBlocked dispense flag
Optimization
Offline-first: rules cached locally (24h TTL)SLA: < 200ms

④ Feedback Loops — Refinement Cycles Between Agents
🔬 Clinical Safety ↔ Data Curation Loop
→Dispenser reports unexpected interaction not in the DB
↻Clinical agent flags unknown pair to Data Curation queue
↻Data Curation validates vs. WHO / BNF; proposes new rule
↻Pharmacist reviews → approves → DB patch applied
↻Clinical agent reloads rules; counselling cache invalidated
Cycle time: < 72h for MODERATE · < 4h for MAJOR/CONTRAINDICATED
📦 Inventory ↔ Orchestrator Accuracy Loop
→Predicted stockout doesn't materialize (false alarm)
↻Actual vs. predicted diff scored per product per pharmacy
↻Orchestrator adjusts lead-time parameter for that category
↻Model re-calibrated after 30-day rolling accuracy window
Target forecast accuracy: ≥ 80% within a 5-day prediction window
📋 Compliance ↔ Clinical Safety Loop
→PIC credential expires → compliance agent flags RED
↻Clinical agent receives "no valid PIC" signal
↻All MAJOR/CONTRAINDICATED dispensing blocked until PIC reinstated
↻Compliance agent monitors renewal; re-enables clinical PIN flow
Enforces TMDA: no unsupervised high-risk dispensing without a valid PIC
📊 BI Agent ↔ Orchestrator Nudge Loop
→BI agent scores trial pharmacy as high-churn risk
↻Orchestrator queues lightweight in-app nudge (not email spam)
↻If nudge engagement = 0 after 48h → escalate to founder digest
↻Post-trial outcome fed back → BI model accuracy score updated
Nudge cap: 1 per 72h per pharmacy to prevent alert fatigue
🗄 Data Curation ↔ All Agents — Global Recall Sync
→TMDA issues drug recall bulletin
↻Data Curation parses + validates in < 15 min
↻Orchestrator broadcasts to Clinical + Inventory agents
↻Clinical flags active dispense carts with recalled drug
↻Inventory marks affected batches for quarantine
All affected pharmacies receive SMS within 20 min of recall publication
📦 ↔ 📊 Demand + Peer Benchmarking Loop
→Inventory agent detects unusual seasonal demand spike
↻BI agent checks if spike is regional (≥10 opt-in peers confirm)
↻If confirmed → adjust seasonal model with peer aggregate signal
↻Pharmacy gets proactive reorder recommendation before spike hits
Privacy: anonymized aggregates only · Min cohort: 10 pharmacies
⑤ Failure Handling — Detection, Recovery & Safe Degradation
❌ Agent Timeout / No Response
⚠Agent exceeds SLA threshold (200ms clinical, 5s others)
✓Orchestrator retries with exponential backoff (1s → 2s → 4s)
✓After 3 retries: fail-safe response using last cached result
✓Critical path (clinical): block dispense + show "check manually"
✓Non-critical: queue task for async retry + user notification banner
⚡ Circuit Breaker — Cascading Failures
⚠5 agent failures within a 60-second window
✓Orchestrator opens circuit: stops routing to failing agent
✓Half-open probe after 30s: sends one test request
✓If probe succeeds → close circuit + resume normal routing
✓Founder alert if circuit stays open for more than 5 min
📵 Offline / No Connectivity
⚠connectivityStore detects offline state (Zustand)
✓Clinical agent uses locally cached rules (24h TTL) — zero degradation
✓All writes go to local sync queue (StockMovement, Dispensing)
✓BI / Compliance agents queued; no alert sent until back online
✓Sync worker flushes queue on reconnect; server wins on inventory level
🔒 Low Confidence Score (< 0.85)
⚠Agent returns result with confidence score below threshold
✓Orchestrator re-routes with a broader context window
✓Second attempt: adds drug aliases + interaction source references
✓Clinical: if still < 0.85 → mandatory PIC manual review flag
✓Data Curation: item added to human pharmacist review queue
🔄 Stale / Conflicting Data
⚠Sync conflict between offline write and server state
✓SyncConflict table records both versions with timestamps
✓Inventory: server wins (authoritative stock level)
✓Transactions: append-only — both versions preserved in ledger
✓Drug rules: flagged for pharmacist resolution in review dashboard
🧪 Data Quality Failure in Curation
⚠TMDA feed contains malformed or missing registration number
✓Validation schema rejects record; adds it to error queue
✓Existing DB record preserved — no overwrite on bad data
✓Error surfaced in Data Review dashboard with source reference
✓Daily error digest sent to SUPER_ADMIN for manual triage
